# 🛠️ PromptBuddy Setup Guide

Welcome to PromptBuddy! follow these simple steps to get your AI-powered creative assistant up and running in minutes.

---

## 📋 Prerequisites

- **Google Chrome** (or any Chromium-based browser like Brave, Edge, Arc).
- A **Google Account** (to get your free API key).

---

## Step 1: Get Your Free Gemini API Key 🔑

PromptBuddy uses Google's powerful Gemini AI, which requires an API key. Don't worry, it's free for most users!

1. Go to **[Google AI Studio](https://aistudio.google.com/app/apikey)**.
2. Click the blue **"Create API key"** button.
3. Select your Google Cloud project (or create a new one automatically).
4. Click **"Create API Key in new project"**.
5. **Copy** the generated key string (it starts with `AIza...`).
   - *Keep this key safe! You'll need it in Step 3.*

---

## Step 2: Install the Extension 🧩

Since PromptBuddy is a developer tool, you'll install it in "Developer Mode".

1. Download the PromptBuddy code to your computer (if you haven't already).
   - *If it's a ZIP file, unzip it first to get the folder.*
2. Open Chrome and type `chrome://extensions` in the address bar.
3. Turn on **Developer mode** using the toggle switch in the top-right corner.
4. Click the **"Load unpacked"** button (top-left).
5. Select the **PromptBuddy folder** on your computer.
   - *Important: Select the folder itself, not a file inside it.*
6. You should now see the **PromptBuddy card** appear in your list of extensions!

---

## Step 3: Configure Your API Key ⚙️

Now verify the connection to Google's AI.

1. Click the **Extensions puzzle piece icon** in Chrome's top-right toolbar.
2. Pin 📌 **PromptBuddy** for easy access.
3. Click the PromptBuddy icon to open the popup.
4. Go to the **"Prompts"** tab (it should be open by default).
5. Paste your API key into the **"Gemini API Key"** field.
6. Click **"💾 Save Settings"**.
   - *You should see a green "Settings Saved!" message.*

---

## Step 4: Test It Out! 🎉

### Test 1: Generate an Image Prompt
1. Go to any website with images (e.g., Unsplash, Pinterest, or Google Images).
2. **Right-click** on an image.
3. Select **"✨ Generate Image Prompt"** from the menu.
4. Wait a few seconds... an overlay should appear with a detailed AI prompt!

### Test 2: Virtual Try-On
1. Open the PromptBuddy popup and switch to the **"Virtual Try-On"** tab.
2. Upload a photo of yourself.
3. Go to an online store (like Amazon or Zara).
4. In the popup, click **"Click to Pick Product"**.
5. Click on a product image on the webpage.
6. Open the popup again and click **"Generate Try-On"**.
7. Validate that the AI swaps the clothing!

---

## ❓ Troubleshooting

- **"I don't see the context menu item."**
  - Try reloading the webpage (`Cmd+R` or `F5`). Extensions sometimes need a page reload to activate.
- **"It says 'No API Key found'."**
  - Open the popup and ensure your key is pasted and saved. Try refreshing the extension in `chrome://extensions`.
- **"The Virtual Try-On hangs."**
  - This feature uses a heavy AI model. Ensure your internet connection is stable. The first run might take 30-60 seconds.
